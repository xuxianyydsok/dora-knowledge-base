# 改进建议文件夹（improvement/）

本文件夹存放 **Dora / Dora Studio 的系统级改进建议**，供站长决策、供执行 Agent 施工。

**从这里开始读**：[`00-总览与阅读指引.md`](./00-总览与阅读指引.md)

## 文件索引

| 编号 | 文件 | 主题 |
| --- | --- | --- |
| 00 | `00-总览与阅读指引.md` | 总览、优先级总表、推进节奏、怎么用这套文档 |
| 01 | `01-UI设计系统与视觉升级.md` | 设计令牌、组件规范、字体配色动效 |
| 02 | `02-页面与交互体验清单.md` | 逐页问题清单（P0/P1/P2 + 工作量） |
| 03 | `03-影视与音乐源与播放体验.md` | 源长效机制、健康面板、4K/音质边界 |
| 04 | `04-内容体系与账号权限.md` | 公开/私密、注册登录、后台、域名邮箱、图床 |
| 05 | `05-架构工程质量与协作规范.md` | 架构、测试、CI/CD、分支策略、技术债 |
| 06 | `06-功能扩展与产品路线.md` | 定位、模块地图、三期路线图、成本额度 |
| 07 | `07-给执行Agent的提示词包.md` | 可直接复制粘贴的派活提示词 |

## 约定

- 只放**建议与方案**，不放代码实现。
- 每份文档只讲一类事，不合并成大杂烩。
- 做完一批改进，回来划掉对应条目，并在 `docs/progress.md` 记一笔。
- 本文件夹**同时只允许一个 Agent 写**（见 `~/AGENTS.md` 第 10 节零共享写入）。
